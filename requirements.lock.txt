# Pinned direct dependencies for a known-good Vector Lake environment.
#
# This file pins the *direct* dependencies resolved on 2026-09-16
# (Windows, CPython 3.13), minus two stale entries dropped on 2026-09-20 (see
# below).  It is a reproducibility aid, not a full
# transitive lock: transitive dependency versions are still decided by the
# resolver, and no artifact hashes are recorded.
#
# To produce a fully locked, hash-verified file once network access to a
# package index is available:
#
#   python -m pip install pip-tools
#   pip-compile --generate-hashes --output-file=requirements.lock.txt requirements.txt
#
# Install the pinned set with:
#
#   python -m pip install -r requirements.lock.txt
#
# Notes
# -----
# * python-louvain is gone: community detection is Leiden via leidenalg+igraph.
# * networkx and jieba pins dropped 2026-09-20: both were leaves of a dependency
#   this project no longer has.  jieba was the pure-Python tokenizer fallback
#   removed on 2026-09-18; networkx was python-louvain's requirement before Leiden
#   (igraph's PageRank replaced it).  No distribution in requirements.txt requires
#   either -- the only remaining edges are igraph's `test` extra and, outside this
#   project's declared set, torch.  Tree shape: -2 leaf packages, and neither had
#   dependents inside the declared set.
# * watchdog was replaced by watchfiles on 2026-09-25: the daemon's two monitors now run on
#   the Rust `notify` crate through a PyO3 binding (one watcher loop per directory, because
#   watchfiles fixes recursion per call).  watchdog's per-handler event surface is kept by a
#   local `_WatchEvent`/`FileSystemEventHandler` shim, so the handler bodies and their tests
#   are unchanged.  A removal the tree does not check is a removal that comes back, so
#   tests/test_dependency_manifest.py pins both the absence of watchdog and the presence of
#   watchfiles.
# * bm25s removed 2026-09-25: the pool rerank is now a required call into the Rust core
#   (``vector_lake_core.fast_bm25_rerank``).  It was never on the hot path here -- the Rust symbol
#   was already preferred and bm25s only ran on hosts without the extension -- so the fallback's
#   only effect was to give those hosts a second, differently-scored engine.  Without the symbol
#   the rerank degrades to the documented no-op (upstream order) and logs it.  Checked by
#   tests/test_dependency_manifest.py, which also pins the import's absence.
# * tantivy added 2026-09-25 as the switch-gated replacement for the FTS5 projection
#   (VECTOR_LAKE_FTS=tantivy, default fts5).  Wheel used:
#   tantivy-0.26.2-cp313-cp313-win_amd64.whl.  The FTS5 tables stay authoritative and
#   tantivy_index.rebuild_from_sqlite() rebuilds the mirror from them, so the switch can be
#   turned off at any time without a migration.
# * rjieba wheel used: rjieba-0.2.1-cp38-abi3-win_amd64.whl, carrying jieba-rs
#   0.9.x.  Update this pin and tokenizer.JIEBA_RS_PINNED together when a
#   binding for jieba-rs 0.11 is published.
# * fastmcp must stay >=4.0: mcp_server.py imports `fastmcp.FastMCP`. The pre-4.x
#   `_tool_manager` registry is gone (the synchronous fallback now reads the local
#   provider's components), so a lower floor silently empties doctor's tool count.
#   4.0.4 verified on Windows/CPython 3.13. It resolves the MCP Python SDK
#   (`mcp` 2.2.0) transitively, so `mcp` is no longer a direct pin.
# * mistune must stay >=3.3.3: 3.0.0 breaks renderer='ast' and 3.3.0-3.3.2 carry
#   GHSA-6m44-fpc8-c3rq (RecursionError DoS via nested emphasis in mistune.html()).
# * fastmcp 4 pulls 27 transitive distributions (fastmcp-slim[client,server]:
#   cyclopts, griffelib, joserfc, authlib, keyring, py-key-value-aio, ...). All
#   resolved versions queried against OSV on 2026-09-17: 0 records.
# * igraph/leidenalg install from cp39/cp38-abi3 wheels; no compiler needed.
